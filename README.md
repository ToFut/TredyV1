# FlowChat React App

A next-generation chat UI with advanced threading, collaboration, and AI suggestions, built with React, Tailwind CSS, and lucide-react icons.

## Features
- Hierarchical, threaded chat with text selection
- AI-powered suggestions and branching
- Collaboration and user presence
- Modern, responsive UI with Tailwind CSS

## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

2. Set up Tailwind CSS (if not already set up):
   ```bash
   npx tailwindcss init -p
   ```
   (This project already includes a basic config.)

3. Start the development server:
   ```bash
   npm start
   # or
   yarn start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project Structure
- `src/FlowChat.jsx` — Main chat component
- `src/App.jsx` — App entry point
- `src/index.js` — React DOM entry
- `src/index.css` — Tailwind CSS imports
- `public/index.html` — HTML template

## Customization
- Edit `src/FlowChat.jsx` to modify chat logic or UI.
- Update Tailwind config for custom styles.
